## POX and simulator code

The starter's original README identifies [noxrepo/pox](https://github.com/noxrepo/pox) as the simulator source and directs readers there for licensing. It is preserved in `docs/UPSTREAM_README.md`.

Existing copyright and license headers in `pox.py`, `pox/`, and `ext/tcpip/` are preserved without alteration. Many files identify James McCauley and the Apache License, Version 2.0; use the notices in each source file and upstream repository for the applicable terms. No standalone license file was present in the downloaded starter archive, so no replacement blanket license is asserted here.

Optional POXDesk/CableBear browser GUI assets and GUI-download/documentation tooling are omitted from this simulation-focused copy. The included course tests do not require them. Real packet-capture/native-extension and real-network modes are not part of the validated workflow.

This archive remains private under the course solution-sharing policy. These provenance notes do not grant additional redistribution rights.
